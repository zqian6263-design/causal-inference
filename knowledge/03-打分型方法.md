# 03 打分型方法深入：GES / DGES / ExactSearch

> **一句话定位**：把「哪个图最可能是真的」变成「哪个图分数最高」，用贪心/精确搜索在图上爬山。causal-learn 提供 GES（贪心）、DGES（确定性关系增强版）、ExactSearch（DP/A* 精确最优）。

## 🎯 打分搜索范式：核心思想

约束型方法（PC/FCI）靠**条件独立性检验**删边定向；打分型方法换了个思路：

1. **定义分数**：给每个候选图算一个「数据拟合程度 − 复杂度惩罚」的分数，分数越高越好
2. **搜索**：在图上做增删边操作，沿着分数上升的方向走

**分数可分解性**（关键性质）：整体分数 = 每个节点「局部分数」之和

$$\text{Score}(G, D) = \sum_{i} \text{LocalScore}(X_i \mid \text{PA}_i)$$

- 好处：增删一条边只影响 2 个节点的局部分数，不用重算全图 → 搜索才能跑得快
- 代价：**分数必须可分解**，所以很多打分型方法只能处理「单维变量、参数可分解」的场景（BIC/BDeu 满足；CV/边际似然用回归模型近似）

**输出语义**：打分型方法输出 **CPDAG**（和 PC 一样，受马尔可夫等价类限制，方向歧义的部分保留无向边）。

## ① GES：Greedy Equivalence Search

### 核心思想

GES 不是直接搜 DAG，而是在**等价类空间（CPDAG 空间）**上爬山，分两阶段：

| 阶段 | 操作 | 直观理解 |
|---|---|---|
| **前向（Forward）** | 不断加边，选分数增益最大的 | 从空图开始，能加就加 |
| **后向（Backward）** | 不断删边，选分数增益最大的 | 过拟合了再剪枝 |

论文（Chickering 2002）证明了在**足够样本 + 忠实性**下 GES 能找到全局最优 CPDAG——这是它比普通贪心 DAG 搜索（如 hill-climbing）更强的地方。

### API 与参数

```python
from causallearn.search.ScoreBased.GES import ges

Record = ges(X, score_func='local_score_BIC', maxP=None, parameters=None)
G = Record['G']          # GeneralGraph（CPDAG）
```

| 参数 | 含义 |
|---|---|
| `X` | 数据，(样本数, 变量数) |
| `score_func` | 打分函数名（见下文打分函数表），默认 BIC |
| `maxP` | 每个节点允许的最大父节点数（限制搜索空间，加速） |
| `parameters` | CV/边际似然打分需要的参数（kfold/lambda/dlabel） |

**返回 `Record` 字典**：`G`（最终图）、`G_step1/G_step2`（前后向阶段的中间图）、`update1/update2`（阶段日志）、`score`（最终分数）。

### 最小示例（线性高斯，完美恢复）

```python
import sys; sys.path.insert(0, '..')          # 允许 import scripts/
import numpy as np
from causallearn.search.ScoreBased.GES import ges
from scripts.data_gen import simulate_linear_gaussian
from scripts.evaluate import evaluate_graph

data, truth = simulate_linear_gaussian(n=30000, seed=42)   # 5 节点 7 边真值 DAG
Record = ges(data)                                          # 默认 BIC 打分
m = evaluate_graph(truth, Record['G'])                      # SHD=0, P/R=1.0
print(m)
```

## ② DGES：处理确定性（函数）关系的 GES 增强版

### 为什么需要它

当数据里有**确定性关系**（如 `X2 = 2*X1 - X3`，无噪声），标准 BIC 打分会**退化**：残差方差为 0，分数变无穷/不稳定，GES 直接失灵。这是打分型方法的经典坑。

### DGES 的解决（三阶段）

1. **Phase 1 — 检测 MinDC**：用协方差矩阵的特征值分析，找出「确定性最小簇」（Minimal Deterministic Clusters）——一组变量里某个是其余变量的确定函数
2. **Phase 2 — DC 感知的 GES**：前向阶段**强制**在 MinDC 内部加边，后向阶段**保护**这些边不被删；用能容忍零残差的确定性 BIC 打分
3. **Phase 3 — 局部精确搜索**（可选，默认关）：对确定性簇邻域做 ExactSearch 精修

> 无确定性关系时，DGES 行为与标准 GES 完全一致（可作 GES 的平替）。

### API 与参数

```python
from causallearn.search.ScoreBased.DGES import dges

Record = dges(X, score_func='local_score_BIC_from_cov_deterministic',
              parameters=None, skip_exact_search=True, node_names=None)
G = Record['G']
```

| 返回键 | 含义 |
|---|---|
| `det_clusters` | 检测到的确定性簇（节点索引数组列表） |
| `mindcs` / `mindc_sets` | 最小确定性簇的分解结果 |
| `G` | 最终图 |
| `exact_search_nodes` | Phase 3 精修涉及节点（若开启） |

### 最小示例（确定性数据，对比 GES vs DGES）

```python
import numpy as np
from causallearn.search.ScoreBased.GES import ges
from causallearn.search.ScoreBased.DGES import dges

rng = np.random.RandomState(42)
n = 3000
x0 = rng.randn(n); x1 = rng.randn(n)
x2 = 2.0 * x0 - 1.5 * x1                      # 确定性: X2 是 X0,X1 的线性函数
Xd = np.column_stack([x0, x1, x2])

rec_g = ges(Xd)                                # 标准 GES: 在确定性数据上退化
rec_d = dges(Xd)                               # DGES: 检测到 MinDC={0,1,2}
print(rec_d['mindc_sets'])                     # [frozenset({0, 1, 2})]
```

## ③ ExactSearch：DP / A* 精确搜索

### 核心思想

不再贪心，直接**搜遍所有 DAG 找全局最优**。5 节点 578 个 DAG、10 节点 4.2×10¹⁸ 个——所以只能用**动态规划（DP）**或 **A\*** 剪枝，且图必须小（≤ ~15 节点）。

### API 与参数

```python
from causallearn.search.ScoreBased.ExactSearch import bic_exact_search

dag_est, stats = bic_exact_search(X, super_graph=None, search_method='astar',
                                  use_path_extension=True, use_k_cycle_heuristic=False,
                                  k=3, verbose=False, include_graph=False, max_parents=None)
```

| 参数 | 含义 |
|---|---|
| `super_graph` | 二分掩码限制搜索空间（已知不可能有边的位置置 0） |
| `search_method` | `'astar'`（A*，更快）或 `'dp'`（动态规划） |
| `use_k_cycle_heuristic` | A* 的 k-环冲突启发式（加速但有近似） |
| `max_parents` | 限制每个节点父数（k-learn，大幅加速） |

**返回**：`dag_est` 邻接矩阵（**DAG**，不是 CPDAG！精确搜索在 DAG 空间做，分数等价类内选代表）；`stats` 搜索统计。

> 小样本 + 小图 + 追求最优时用它；10 节点以上慎用。

## ⭐ 打分函数选型（Score Functions）

| 打分函数 | 导入（causallearn.score.LocalScoreFunction） | 适用数据 | 说明 |
|---|---|---|---|
| **BIC** | `local_score_BIC` | 线性高斯连续 | 默认首选；线性回归残差 + 复杂度惩罚 |
| **BDeu** | `local_score_BDeu` | 离散多值 | 贝叶斯分数；需 `sample_prior`/`r_i_map` 参数 |
| **CV_general** | `local_score_cv_general` / `_multi` | 非线性（RKHS 回归） | 负 k 折交叉验证对数似然；慢；`kfold`/`lambda`/`dlabel` |
| **marginal_general** | `local_score_marginal_general` / `_multi` | 非线性（RKHS 回归） | 负边际似然；比 CV 快一点 |

选型逻辑：**连续线性 → BIC；离散 → BDeu；非线性 → CV/marginal_general**（牺牲速度换非参数灵活性）。

## ⚠️ 局限（务必记住）

1. **分数可分解性**是前提——多变量联合分布 / 复杂模型不好直接用
2. **输出 CPDAG**：等价类内方向不可识别（除非用 exact search 的 DAG 输出，那也是代表元）
3. **BIC 在确定性数据上退化**——用 DGES 或加噪声扰动
4. **ExactSearch 图大小受限**（≤15 节点），super_graph 先验可救命
5. 与约束型相比：不需要显式选独立性检验，但**分数选择**同样影响结果（选错打分 = 选错假设）
