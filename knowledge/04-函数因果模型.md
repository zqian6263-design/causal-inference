# 04 函数因果模型深入：LiNGAM 家族 / ANM / PNL

> **一句话定位**：不靠独立性检验、不靠打分，而是**假设数据背后的因果机制有特定函数形式**，利用「噪声独立性 / 函数可逆性」直接识别完整方向——这类方法能学到比 PC 更强的 **DAG**（不是 CPDAG）。

## 🎯 范式核心：为什么函数形式能识别方向

PC 只能学到 CPDAG 是因为：对链 `X→Y→Z` 和 `X←Y←Z`，**观测分布完全一样**，统计学上不可区分。函数因果模型打破了这一点：

- **LiNGAM**（线性非高斯）：假设 `X_j = Σ β_ji X_i + E_j`，噪声 `E_j` **非高斯且相互独立**。非高斯性让「方向」从分布里可识别——用独立成分分析（ICA）把混合信号分解回独立源，顺序就是因果序
- **ANM**（加性噪声模型）：假设 `Y = f(X) + E`，`E ⊥ X`。如果数据真由 `X→Y` 生成，则 `Y - f(X)` 与 `X` 独立；反过来对 `X = g(Y) + E'` 一般**不成立**（除非特殊函数）→ 方向可判
- **PNL**（后非线性）：`Y = g(f(X) + E)`，比 ANM 多一个后非线性变换，假设更宽松

**代价**：假设严格。数据不符合函数形式 → 方法失灵（甚至会给出错误方向）。这就是「靠假设吃饭」的范式。

## ① LiNGAM 家族（causallearn.search.FCMBased.lingam）

统一接口（sklearn 风格）：

```python
from causallearn.search.FCMBased import lingam

model = lingam.ICALiNGAM(random_state=42)
model.fit(X)
model.causal_order_        # 因果顺序（数组，前面的先发生）
model.adjacency_matrix_    # 系数矩阵 B（B[i,j] = j→i 的系数）
```

| 方法 | 适用场景 | 关键参数 |
|---|---|---|
| **ICALiNGAM** | 经典 LiNGAM；快但依赖 ICA 收敛 | `random_state`、`max_iter` |
| **DirectLiNGAM** | 无 ICA，逐步回归选择；支持先验知识 | `prior_knowledge`、`measure`（'pwling'/'kernel'） |
| **VARLiNGAM** | **时序**数据（含滞后因果） | `lags`、`criterion`（aic/bic…）、`prune` |
| **RCD / CAM-UV** | 带隐变量/未观测混杂的扩展 | RCD：官方实现，批次 C 已加最小调用（`lingam.RCD`，见 04/run.py 示例 5）；**CAM-UV：官方实现，未单独实验**（依赖 pygam 本机未装，见 04/run.py 顶部注释） |

**`prior_knowledge` 矩阵语义**（DirectLiNGAM）：`P[i,j] = 0` 表示 **i 没有到 j 的有向路径**；`= 1` 表示 **i 到 j 有有向路径**；`= -1` 表示**无先验**。

> ⚠️ **关键坑**：ICA-LiNGAM 依赖**非高斯噪声**。用纯高斯数据跑必然退化（FastICA 不收敛警告）——这不是 bug，是方法前提被违反。

## ② ANM / PNL：成对方向判断

causal-learn 的 ANM/PNL 只做**两个变量间的方向判断**（多变量请先用 PC 找骨架，再对无向边逐对定向）：

```python
from causallearn.search.FCMBased.ANM.ANM import ANM
from causallearn.search.FCMBased.PNL.PNL import PNL

anm = ANM()
p_forward, p_backward = anm.cause_or_effect(data_x, data_y)   # data: (n,1)

pnl = PNL()
p_forward, p_backward = pnl.cause_or_effect(data_x, data_y)
```

**p 值解读**：p 值大 = 接受该方向（噪声独立假设成立）。
- `p_forward` 大 & `p_backward` 小 → **x→y**
- 两者都大 → 方向不可判（两方向都行）
- 两者都小 → 两个方向都不符合 ANM 假设（可能非线性非加性）

> ⚠️ PNL import 较慢（~45s，依赖较重）；小样本（<500）下结果不稳。

## 📊 方法与数据类型的匹配

| 数据特征 | 推荐 | 理由 |
|---|---|---|
| 线性 + 非高斯噪声 | **LiNGAM** 家族 | 非高斯性直接解锁完整 DAG |
| 线性 + 高斯噪声 | LiNGAM 失效 → 退回 PC/GES | 高斯下方向不可识别（等价类） |
| 非线性 + 加性噪声 | **ANM** | 加性噪声可识别方向 |
| 非线性 + 后非线性 | **PNL** | 更一般但更慢更脆 |
| 时序 | **VAR-LiNGAM** / Granger | 滞后结构 |

## ⚠️ 局限（务必记住）

1. **假设严格**：线性（LiNGAM）/ 加性（ANM）/ 后非线性（PNL），且噪声独立——违反即失效
2. **高斯数据是 LiNGAM 的盲区**：方向不可识别（信息论上）
3. ANM/PNL 只做**成对**判断，多变量要配合 PC
4. 非参数变体（DirectLiNGAM measure='kernel'、CV_general）慢，样本大时耐心等或换 pwling
5. 这类方法输出的是**因果序/系数矩阵**，转成图时 `B[i,j]` 非零表示 `j→i`
