# 05 隐变量与排列方法深入：GIN / RLCD / GRaSP / BOSS

> **一句话定位**：两类「进阶」方法——GIN/RLCD 处理**隐藏变量**（观测变量背后有未测到的共同原因），GRaSP/BOSS 用**排列视角**找因果序再定图（比打分搜索更稳）。

## ① GIN：广义独立噪声条件（隐变量 + 非高斯）

### 核心思想

GIN（Generalized Independence Noise，2021）针对 **LiNLAM**（线性非高斯隐变量模型）：

$$X = BX + \Lambda L + E$$

其中 `L` 是隐变量（latent），`E` 非高斯独立噪声。GIN 利用「观测变量与隐变量之间秩结构的约束」逐层剥离隐变量影响，输出**观测变量间的因果图 + 因果序**。

### API

```python
from causallearn.search.HiddenCausal.GIN.GIN import GIN

G, K = GIN(data)
# G: GeneralGraph（因果图）
# K: 因果序（causal order）
```

> GIN 假设线性 + 非高斯（LiNGAM 家族思路）+ 隐变量之间无因果关系，比较专门，日常分析用得少。

## ② RLCD：秩约束隐变量发现（推荐了解）

### 核心思想

RLCD（Rank-based Latent Causal Discovery，2025）利用**部分观测线性因果模型的秩约束**：隐变量会让观测协方差矩阵出现「秩亏」结构，通过秩检验（χ² 或 Spearman）发现隐藏的共同原因。

### API 与返回

```python
from causallearn.search.HiddenCausal.RLCD import Chi2RankTest, RLCD
from causallearn.graph.NodeType import NodeType

cg = RLCD(data, ranktest_method=Chi2RankTest(data), maxk=2)
# cg.G: CausalGraph，含观测节点 + 检测到的隐变量节点（L1, L2, ...）
latents = [n.get_name() for n in cg.G.get_nodes()
           if n.get_node_type() == NodeType.LATENT]
```

| 返回属性 | 含义 |
|---|---|
| `cg.G` | 完整图（观测 + 隐变量 L1…） |
| `cg.stage1_cg` | 第一阶段仅观测变量的图 |
| `cg.adjacency` | 含隐变量的邻接矩阵 |
| `cg.all_vars` | 观测变量 + 检测到的隐变量列表 |

**教学示例**：5 个观测变量由一个共享隐变量生成 → RLCD 正确检测出 `L1`。

## ③ GRaSP：稀疏排列的贪心松弛

### 核心思想

先找**因果序**（变量排列，前面的不能是后面的祖先）再定图。GRaSP（Greedy Relaxations of the Sparsest Permutation）是「最稀疏排列」准则的贪心近似：找到能让图最稀疏的变量顺序。

### API

```python
from causallearn.search.PermutationBased.GRaSP import grasp

G = grasp(X, score_func='local_score_BIC', depth=None, parameters=None)
```

**图矩阵编码约定**（重要，GRaSP/BOSS 通用）：
- `G.graph[j,i] = 1` 且 `G.graph[i,j] = -1` → **i → j**
- `G.graph[i,j] = G.graph[j,i] = -1` → **i — j**（无向）

## ④ BOSS：最佳序打分搜索

### 核心思想

BOSS（Best Order Score Search）在**排列空间**上搜索使 BIC 分数最优的因果序，然后一次性确定图结构。对超稀疏/超密集图都较稳。

### API

```python
from causallearn.search.PermutationBased.BOSS import boss

G = boss(X, score_func='local_score_BIC', parameters=None)
```

## 📊 方法与场景匹配

| 场景 | 推荐方法 | 说明 |
|---|---|---|
| 怀疑有**隐变量**（未测混杂） | **RLCD** / GIN / FCI | RLCD 输出隐变量节点，FCI 输出 PAG |
| 线性非高斯、追求完整 DAG | **GRaSP** / LiNGAM | GRaSP 实测恢复优秀 |
| 样本少、图小、要精确 | BOSS / ExactSearch | 排列搜索对噪声稳健 |
| 通用默认（连续线性） | GRaSP（实测 SHD=0） | 比 GES 更稳（本实验数据） |

## ⚠️ 局限（务必记住）

1. **GIN/RLCD**：假设线性结构 + 隐变量间无因果，模型较专门
2. **排列型方法**输出的是 CPDAG（BOSS 可给 DAG 代表元）；打分函数选择影响大
3. RLCD 的 `ranktest_method` 必填（`Chi2RankTest(data)` 或 Spearman），忘了会报错
4. 隐变量方法在小样本下容易把「噪声相关性」误判为隐变量——结果要结合领域知识审
