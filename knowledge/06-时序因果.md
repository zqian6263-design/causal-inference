# 06 时序因果：Granger 因果（线性）

> **一句话定位**：时间序列专用——「过去能不能预测未来」。`X 格兰杰导致 Y` 定义为：**用 X 的滞后值能显著提升对 Y 的预测**（回归显著性检验或 lasso 稀疏选择）。

## 🎯 核心思想与注意

**预测 ≠ 因果**：Granger 因果本质是「时序上的预测性」，不等同于真正干预意义上的因果。但在**时序数据**上，它是计算便宜、解释直观的首选筛选工具，配合领域知识使用。

causal-learn 提供两种实现：
1. **回归 + 假设检验**（`granger_test_2d`）：两变量，F 检验滞后项是否显著
2. **Lasso 回归**（`granger_lasso`）：多变量，用 L1 稀疏选择哪些滞后项有预测力

## API

```python
from causallearn.search.Granger.Granger import Granger

G = Granger()

# 二维时序（x1 是否格兰杰导致 x2）
p_value_matrix = G.granger_test_2d(data_2d)    # data_2d: (n_samples, 2)

# 多维时序（lasso 稀疏选择）
coeff = G.granger_lasso(data_nd)               # data_nd: (n_samples, n_features)
```

| 参数/返回 | 说明 |
|---|---|
| `data` | (样本数, 变量数)；`granger_test_2d` 必须是 2 列 |
| `p_value_matrix` | 双向格兰杰检验的 p 值（小 = 显著） |
| `coeff` | lasso 系数矩阵（非零项 = 有预测力的滞后连接） |

## 最小示例

```python
import numpy as np
from causallearn.search.Granger.Granger import Granger

rng = np.random.RandomState(42)
n = 2000
x1 = rng.randn(n)
x2 = np.zeros(n)
for t in range(1, n):
    x2[t] = 0.6 * x2[t-1] + 0.5 * x1[t-1] + 0.3 * rng.randn()   # x1 滞后影响 x2

G = Granger()
pmat = G.granger_test_2d(np.column_stack([x1, x2]))    # x1→x2 显著（p 小）
coeff = G.granger_lasso(np.column_stack([x1, x2, rng.randn(n)]))
```

## ⚠️ 局限（务必记住）

1. **线性**：只捕捉线性滞后关系；非线性时序用 VAR-LiNGAM 或深度学习类方法
2. **预测性 ≠ 因果性**：混入共同驱动因素（如隐藏的气候因子同时驱动多个变量）会出假阳性
3. 滞后阶数要合理设定（太少漏、太多虚）；数据须**平稳**或先差分
4. 高维时序用 lasso 版（`granger_lasso`），两变量用检验版（`granger_test_2d`）
