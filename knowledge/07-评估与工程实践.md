# 07 评估与工程实践：指标、可视化、缓存、数据集

> **一句话定位**：因果发现算法跑完了，怎么判断好不好？这篇讲 causal-learn 的评估工具（SHD/混淆矩阵）、图可视化、CI 结果缓存、内置数据集，以及本项目的统一评估规范（scripts/evaluate.py）。

## ① 评估指标（causallearn.graph）

因果发现评估的**黄金法则**：约束型输出 CPDAG/PAG、打分型输出 CPDAG、函数模型输出 DAG——**评估前必须对齐语义**（真值 DAG → CPDAG 用 `dag2cpdag`），否则 SHD 虚高没有意义。

| 指标 | 类（causallearn.graph） | 含义 |
|---|---|---|
| **SHD** | `SHD(truth, est).get_shd()` | 结构汉明距离：边增删 + 方向错误的总数，**越小越好** |
| Adjacency P/R | `AdjacencyConfusion` | 边（无视方向）的精确率/召回率 |
| Arrow P/R | `ArrowConfusion` | 有向箭头的精确率/召回率 |

```python
from causallearn.graph.SHD import SHD
from causallearn.graph.AdjacencyConfusion import AdjacencyConfusion
from causallearn.graph.ArrowConfusion import ArrowConfusion
from causallearn.utils.DAG2CPDAG import dag2cpdag

truth_cpdag = dag2cpdag(truth_dag)          # 真值 DAG → CPDAG 对齐
shd  = SHD(truth_cpdag, est).get_shd()
adj  = AdjacencyConfusion(truth_cpdag, est) # get_adj_precision/recall/tp/fp/fn
arr  = ArrowConfusion(truth_cpdag, est)     # get_arrows_precision/recall
```

**本项目统一封装**：`scripts/evaluate.py` 的 `evaluate_graph(truth_adj, est)` 返回 dict（SHD/P/R/TP/FP/FN + 时间），所有实验脚本复用。

## ③ CI 结果缓存（cache_path）——KCI 慢的救星

KCI 等核方法极慢（5 节点 2500 样本 ~17 分钟）。causal-learn 支持把独立性检验 p 值缓存到 JSON，**调参不重算**：

```python
cg1 = pc(data, 0.05, kci, cache_path='cache_kci.json')   # 首次跑，慢
cg2 = pc(data, 0.05, kci, cache_path='cache_kci.json', uc_rule=1)  # 秒回，复用 p 值
```

加载时会校验数据 hash 与参数 hash，保证缓存一致。
