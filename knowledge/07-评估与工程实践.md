# 07 评估与工程实践：指标、可视化、缓存、数据集

> **一句话定位**：因果发现算法跑完了，怎么判断好不好？这篇讲 causal-learn 的评估工具（SHD/混淆矩阵）、图可视化、CI 结果缓存、内置数据集，以及本项目的统一评估规范（scripts/evaluate.py）。

## ① 评估指标（causallearn.graph）

因果发现评估的**黄金法则**：约束型输出 CPDAG/PAG、打分型输出 CPDAG、函数模型输出 DAG——**评估前必须对齐语义**（真值 DAG → CPDAG 用 `dag2cpdag`），否则 SHD 虚高没有意义。

| 指标 | 类（causallearn.graph） | 含义 |
|---|---|---|
| **SHD** | `SHD(truth, est).get_shd()` | 结构汉明距离：边增删 + 方向错误的总数，**越小越好** |
| Adjacency P/R | `AdjacencyConfusion` | 边（无视方向）的精确率/召回率 |
| Arrow P/R | `ArrowConfusion` | 有向箭头的精确率/召回率 |

```python
from causallearn.graph.SHD import SHD
from causallearn.graph.AdjacencyConfusion import AdjacencyConfusion
from causallearn.graph.ArrowConfusion import ArrowConfusion
from causallearn.utils.DAG2CPDAG import dag2cpdag

truth_cpdag = dag2cpdag(truth_dag)          # 真值 DAG → CPDAG 对齐
shd  = SHD(truth_cpdag, est).get_shd()
adj  = AdjacencyConfusion(truth_cpdag, est) # get_adj_precision/recall/tp/fp/fn
arr  = ArrowConfusion(truth_cpdag, est)     # get_arrows_precision/recall
```

**本项目统一封装**：`scripts/evaluate.py` 的 `evaluate_graph(truth_adj, est)` 返回 dict（SHD/P/R/TP/FP/FN + 时间），所有实验脚本复用。

## ② 图可视化（GraphUtils）

```python
from causallearn.utils.GraphUtils import GraphUtils

pyd = GraphUtils.to_pydot(cg.G)             # CausalGraph/GeneralGraph → pydot
pyd.write_png('graph.png')

# 新式彩色图（v0.1.4.x）
GraphUtils.plot_graph(Record['G'], labels=['Age', 'Income'],
                      colors={'Age': 'lightblue'}, title='...', save_path='g.png')
```

> ⚠️ **本机实测（批次 C）**：`to_pydot().write_png()` 依赖外部 graphviz 二进制 `dot`，**本机未安装**（`FileNotFoundError: dot not found`）；`GraphUtils.plot_graph` 同样内部走 pydot，也会失败。本项目改用 **`scripts/plotting.py`**（matplotlib + networkx 直渲，CPDAG/PAG 通用）落盘 PNG：
>
> ```python
> from scripts.plotting import plot_graph
> plot_graph(cg.G, "results/figs/graph.png", title="...")
> ```
>
> **graphviz 是可选依赖**：装了系统级 graphviz 即可用 `to_pydot`/`plot_graph` 原生渲染；未装也不影响实验——全部脚本走 `plotting.py`（仅依赖 requirements.txt 内包）。

## ③ CI 结果缓存（cache_path）——KCI 慢的救星

KCI 等核方法极慢（5 节点 2500 样本 ~17 分钟）。causal-learn 支持把独立性检验 p 值缓存到 JSON，**调参不重算**：

```python
cg1 = pc(data, 0.05, kci, cache_path='cache_kci.json')   # 首次跑，慢
cg2 = pc(data, 0.05, kci, cache_path='cache_kci.json', uc_rule=1)  # 秒回，复用 p 值
```

加载时会校验数据 hash 与参数 hash，保证缓存一致。

## ④ 内置数据集

```python
from causallearn.utils.Dataset import load_dataset
data, labels = load_dataset('sachs')       # 'sachs' | 'boston_housing' | 'airfoil'
```

真实数据集**没有真值图**——只能做方法演示/交叉验证，不能算 SHD。I 轮已实跑（`11_doc_coverage`，PC+fisherz）：

| 数据集 | 样本×变量 | PC 边数 |
|---|---|---|
| sachs（蛋白信号） | 7466×11 | 25 |
| boston_housing | 506×14 | 21 |
| airfoil（翼型噪声） | 1503×6 | 10 |

> ⚠️ **Windows 坑（I 轮实测）**：Anaconda py3.9 的 urllib 默认 SSL 上下文加载系统证书失败（`ASN1 NOT_ENOUGH_DATA`）→ `load_dataset` 下载失败。规避：`ssl.create_default_context(cafile=certifi.where())` + `urllib.request.install_opener(HTTPSHandler(context=…))`（与 `github_push.py` 同因，脚本内已内置）。

## ⑤ 图操作工具（Graph operations）

| 工具 | 导入 | 用途 | I 轮实证 |
|---|---|---|---|
| `dag2cpdag` | `causallearn.utils.DAG2CPDAG` | 真值 DAG → CPDAG（评估对齐） | 全仓评估管线在用 |
| `dag2pag` | `causallearn.utils.DAG2PAG` | 真值 DAG → PAG（FCI 评估） | 02_fci 在用 |
| `pdag2dag` | `causallearn.utils.PDAG2DAG` | PDAG → 无环一致扩展 DAG | 骨架 7→7 不变、无环=True（`11_doc_coverage`） |
| `txt2generalgraph` | `causallearn.utils.TXT2GeneralGraph` | 从 txt 载入 GeneralGraph | 载入 bnlearn asia 真值图，与手写 parse 逐位一致（`11_doc_coverage`） |
