# 08 方法选型指南：从数据到方法的决策地图 ★

> **用法**：拿到任何因果推断数据分析任务，按本指南三步走——① 看数据特征走决策树；② 查速查表定候选方法；③ 套用实验设计 SOP。第 ② 节已用 Phase 2/3 实证数据（4 类数据 × 全方法，3000 样本，`results/comparison_report.md`）校准。

## ① 决策树：数据特征 → 方法

```text
开始
├─ 数据是时间序列？
│   ├─ 是 → 线性 → Granger / VAR-LiNGAM
│   └─ 否 ↓
├─ 怀疑有未观测隐变量/混杂？
│   ├─ 是 → FCI（PAG）或 RLCD（显式输出隐变量节点）
│   └─ 否 ↓
├─ 变量是离散/分类？
│   ├─ 是 → PC + chisq/gsq（约束型）或 GES + BDeu（打分型）
│   └─ 否 ↓
├─ 关系线性？
│   ├─ 是 → 噪声高斯？
│   │   ├─ 是 → PC + fisherz / GES + BIC / GRaSP / ExactSearch(小图)
│   │   └─ 否（非高斯）→ LiNGAM 家族（完整 DAG）或 GRaSP
│   └─ 否（非线性）→ PC + KCI（慢但稳）或 ANM/PNL（成对方向）
└─ 数据有缺失值 → PC + mv_fisherz（MVPC）或 CD-NOD
```

**决策要点**：
- **要完整 DAG 还是要 CPDAG**？→ 完整 DAG 只有函数模型（LiNGAM/ANM/PNL）能给；其余给 CPDAG（等价类）
- **样本量**：大样本（>10⁴）放心用 KCI；小样本用参数检验（fisherz/chisq）
- **图规模**：>15 节点别用 ExactSearch；大图用 PC（骨架阶段可控）
- **时间成本**：KCI/PNL/CV_general 慢；fisherz/GRaSP/BOSS 亚秒级（5 节点）

## ② 方法速查表（13 个搜索方法）

| 方法 | 范式 | 核心假设 | 输出 | 时间 | 典型场景 |
|---|---|---|---|---|---|
| **PC** | 约束 | 忠实性+无隐变量 | CPDAG | 快 | 通用默认首选 |
| **FCI** | 约束 | 忠实性（允许隐变量） | PAG | 中 | 有混杂的观测研究 |
| **CD-NOD** | 约束 | 数据含时变/域变因子 | CPDAG | 中 | 异质/多域数据 |
| **GES** | 打分 | 分数可分解 | CPDAG | 快 | 连续线性默认 |
| **DGES** | 打分 | 有确定性关系 | CPDAG | 快 | 特征有函数依赖 |
| **ExactSearch** | 打分 | 全局最优 | DAG | 慢(小图) | ≤15 节点追求精确 |
| **ICA-LiNGAM** | 函数 | 线性+非高斯噪声 | DAG | 快 | 非高斯连续 |
| **DirectLiNGAM** | 函数 | 线性+非高斯 | DAG | 快 | 同上+有先验 |
| **VAR-LiNGAM** | 函数 | 线性非高斯+时序 | DAG | 中 | 时序 |
| **ANM** | 函数 | 加性噪声 | 成对方向 | 中 | 非线性成对判断 |
| **PNL** | 函数 | 后非线性 | 成对方向 | 慢 | 更一般的非线性 |
| **GIN** | 隐变量 | 线性非高斯+隐变量 | 图+序 | 中 | LiNLAM 结构 |
| **RLCD** | 隐变量 | 部分观测线性+秩约束 | 图(含L1..) | 中 | 隐变量发现 |
| **GRaSP** | 排列 | 稀疏排列 | CPDAG | 快 | 通用备选 |
| **BOSS** | 排列 | 最优排列 | CPDAG | 快 | 通用（离散/混合强） |
| **Granger** | 时序 | 线性滞后预测 | p/系数 | 快 | 时序筛查 |

（+ 5 种独立性检验：fisherz 线性高斯 / mv_fisherz 缺失 / chisq·gsq 离散 / KCI 非参数慢）

## ②b 实证对比矩阵（Phase 2/3，3000 样本 5 节点 7 边，SHD 越小越好）

| 数据 \ 方法 | PC | GES | GRaSP | BOSS | 结论 |
|---|---|---|---|---|---|
| **线性高斯** | **0** ✅ | **0** ✅ | 5 | **0** ✅ | PC/GES/BOSS 完美；GRaSP 高斯下退化（BIC 打分敏感） |
| **线性非高斯** | 8 | 5 | 5 | 5 | 全体平庸；**ICA-LiNGAM 完美**（order=[0,1,2,3,4], 7 系数） |
| **非线性 ANM** | 4 | 4 | 5 | 5 | 线性假设方法全体受限 → 需 KCI/ANM（非线性场景） |
| **离散** | 7 | 5 | 8 | **1** ✅ | **BOSS 碾压**（排列搜索+BDeu）；chisq 检测力弱 |

**实证结论**（写入选型决策）：
1. **线性高斯数据**：PC+fisherz / GES+BIC / BOSS 三者任选，实测 SHD=0
2. **线性非高斯数据**：LiNGAM 家族是唯一能完美恢复的（完整 DAG）；其余只到 CPDAG 且 SHD≥5
3. **离散数据**：优先 BOSS（SHD=1）；GRaSP 意外最差（SHD=8）——排列型内部差异大
4. **非线性数据**：所有线性假设方法 SHD≥4——务必换 KCI 检验或 ANM/PNL（Phase 2 补充实验待跑）
5. GRaSP 有随机性（内部无 seed 固定），同数据两次跑 SHD 可差 5（0 vs 5）——**结果需多次运行取稳**

> 完整逐项指标（含 P/R/时间）见 `results/comparison_report.md` 与 `results/metrics/comparison.json`。

## ③ 常见场景配方

### 场景 A：通用观测数据（无先验、无隐变量疑云）
**配方**：`PC + fisherz`（线性高斯）或 `GRaSP`（实测 SHD=0）先跑，`GES + BIC` 交叉验证；结果不一致时用 `ExactSearch`（小图）仲裁。
**理由**：三个范式互相印证，一致则可信度高。

### 场景 B：遥感多模态分类的因果特征提取（用户研究方向）
**配方**：① 用 `PC`（或 GRaSP）在特征+标签联合变量上找骨架 → ② 用 `LiNGAM`/`DirectLiNGAM`（非高斯光谱特征常见）定完整方向 → ③ 领域知识校验关键边（如「土壤湿度→植被指数」）→ ④ 取标签的马尔可夫毯（Markov blanket）作为因果特征子集，替代纯相关/纯监督的特征选择。
**理由**：因果特征选择能剔除「伪相关」（混淆导致的虚假关联），提升跨域泛化——这正是 TGRS 方向论文的价值点。

### 场景 C：面板/时序观测（气候-农业等）
**配方**：`Granger` 快速筛查候选连接 → `VAR-LiNGAM` 精细定因果序 → 与领域滞后知识核对。

### 场景 D：怀疑有未测混杂
**配方**：`FCI` 输出 PAG（有向/无向/圆圈端点明确标注不确定性）→ 若需显式隐变量节点用 `RLCD` → 结合背景知识定向。

## ④ 局限与坑速查（实测验证）

| 坑 | 说明 | 规避 |
|---|---|---|
| KCI 极慢 | 5 节点 2500 样本 ~17min | 用 `cache_path` 缓存；大样本换 fisherz |
| LiNGAM 高斯退化 | 高斯噪声下 FastICA 不收敛 | 先检验非高斯性（如用正态性检验） |
| PC 只能到 CPDAG | 等价类方向不可识别 | 需要方向时换 LiNGAM/ANM |
| GES 遇确定性退化 | BIC 在零残差下爆炸 | 用 DGES 或加噪声 |
| SHD 语义错位 | 真值 DAG 直接对比 CPDAG 虚高 | 必须 `dag2cpdag` 对齐 |
| d_separation 不可用 | networkx<3.3 缺 is_d_separator | 用 fisherz 等真实检验 |
| BOSS 偶发不稳 | 排列搜索可能陷局部 | GRaSP 优先，BOSS 备选 |
| PNL import 慢 | ~45s | 批量任务提前 import |

## ⑤ 实验设计 SOP（新数据分析任务套用）

1. **数据盘点**：变量类型（连续/离散）、缺失率、样本量、是否时序、是否可能有隐变量 → 填决策树
2. **方法选择**：按决策树选 2-3 个候选（跨范式互证）
3. **数据准备**：标准化（RLCD 必需）、缺失值处理（MVPC）、离散化（如需要）
4. **运行**：seed=42；用 `scripts/` 工具；指标落盘 `results/metrics/`
5. **评估与解读**：合成数据算 SHD/P/R；真实数据做稳定性检验（bootstrap 重采样看边出现频率）+ 领域知识核对
6. **报告**：方法 × 数据 × 指标表 + 图（GraphUtils 彩色图）+ 结论
