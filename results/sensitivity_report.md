# 样本量敏感性扫描（SHD 随样本量变化）

- 数据: 5 节点 7 边 DAG（TestPC 基准图），样本量梯度 [1000, 3000, 10000, 30000]
- 每格 3 个 seed（[42, 1, 7]），数据逐 seed 重生成；SHD 报 mean±std（越小越好），时间为平均
- 方法: PC+fisherz / GES+BIC / GRaSP+BIC / BOSS+BIC（两行数据）；ICA-LiNGAM 仅线性非高斯（前提吻合）
